# CryoTray v0.0.109

This release focuses on bug fixes, stability improvements, lighter background resource usage, and faster companion window responsiveness across the app.

## Bug Fixes & Stability

- **Storage & Cache Cleanup busy-close crash fix:** Fixed an unhandled error when closing **Storage & Cache Cleanup** and confirming **Yes** while a scan or cleanup was still running; active work now cancels cleanly and the window closes safely.
- **No UI-thread stalls on opening Settings:** Moved startup task synchronization (`schtasks.exe`) and update rollback/download cache folder scans off the UI thread, eliminated duplicate startup control rebuilds, and deferred hidden **Manage profiles** scheme loading until expanded.
- **No hang on closing or switching languages in System Information:** In-flight hardware inventory queries cancel cleanly when closing **System Information** or switching English/Arabic mid-scan, with **Copy** and **Save report** gated cleanly until loading completes.

## Performance & Lighter Idle Footprint

- **Instant non-blocking System Information:** Opens immediately with live sensor and memory readouts while deeper WMI, GPU diagnostics, monitor, network, and event-log details finish in parallel in the background with clear inline loading indicators and smart short-lived caching.
- **Lighter idle tray & background timers:** Eliminated repeated Windows power-scheme re-enumeration on idle ticks when the active power plan has not changed, slowed background plan watch polling while minimized to the tray, and stopped **Autopilot** and **Automatic Standby Cleanup** background timers completely whenever those features are turned off.
- **Debounced idle memory trim:** Coalesces compacting GC and working-set trimming off the UI thread after startup settle, dashboard/companion window closes, focus loss, update checks, storage cleanups, and support bundle exports.
- **Reduced UI memory retention:** Clears temporary dashboard chart and drive lists when hiding to tray and bounds **Settings > About** logo decoding (`144 px`) so idle background RAM stays lean.

## Download

- **Installer (Recommended):** Download `CryoTray-Setup-0.0.109.exe` (includes the bundled PawnIO driver setup) and verify it against `CryoTray-Setup-0.0.109.exe.sha256`.
- **Portable Zip:** Download `CryoTray-0.0.109-win-x64.zip`, verify it against `CryoTray-0.0.109-win-x64.zip.sha256`, extract, run `PawnIO_setup.exe` if the driver is missing, then run `CryoTray.exe`.
- **In-app update:** Later versions arrive through **Settings > About** or the dashboard update banner.
