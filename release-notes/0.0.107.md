# CryoTray v0.0.107

## New

- **`Eco` & `Work` power profiles:** CryoTray now ships with eight built-in power profiles alongside Windows Balanced. `CryoTray — Eco` (`Silent`) combines passive cooling with sub-base thermal caps (`70%` AC / `55%` DC) in a glacier cyan-teal theme (`#2699A8` frame/icons and `#1C7986` toggle track). `CryoTray — Work` (`Productivity`) offers steady, low-power desktop responsiveness in steel-slate.
- **Manage profiles & pin Windows PC plans:** Under **Settings > CPU > Manage profiles & Windows plans**, hide unused built-in profiles (with a one-click **Show all** reset) or pin any existing Windows power scheme as **Cooling Off** or **Cooling On** with a custom name and accent color. CryoTray never modifies or deletes your Windows schemes, and automatically recovers cleanly if a pinned plan is removed outside the app.
- **Profile-synced tray & frame colors:** Window frames, active titlebar icons, toggle switches, CPU chart segments, and 8 px tray `Power Profile` submenu dots follow the active profile. An opt-in **Sync badge color with active power profile** toggle under **Settings > View** also syncs the CPU tray icon color.
- **CPU `GHz` plan speed tooltip & boost cache:** Hovering `GHz` next to `CPU SPEED` shows the active power plan's clock ceiling (`PROCTHROTTLEMAX`, `PERFBOOSTMODE`, `PROCFREQMAX`) for CryoTray, `Balanced`, pinned, and any external Windows scheme. CryoTray auto-detects Boost limits via SMBIOS Type 4, Intel CPUID, WMI, and live core clocks (using a two-sample spike filter and per-CPU caching across restarts, with a **Clear** button under **Settings > CPU** for BIOS/PBO changes).
- **Per-app Cooling in Game Mode & SSD free space:** Assign `Eco` or any Cooling/Cooling-Off profile to individual apps under **Settings > Autopilot** while keeping fullscreen auto-detection on your preferred off profile. Hovering dashboard SSD rows now also shows mounted partition free space (`Free space: X / Y GB (%)`) alongside model, temperature, and SMART health.

## Download

- **Installer (Recommended):** Download `CryoTray-Setup-0.0.107.exe` (includes the bundled PawnIO driver setup) and verify it against `CryoTray-Setup-0.0.107.exe.sha256`.
- **Portable Zip:** Download `CryoTray-0.0.107-win-x64.zip`, verify it against `CryoTray-0.0.107-win-x64.zip.sha256`, extract, run `PawnIO_setup.exe` if the driver is missing, then run `CryoTray.exe`.
- **In-app update:** Later versions arrive through **Settings > About** or the dashboard update banner.
