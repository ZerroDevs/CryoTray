# CryoTray v0.0.106

## New

- **GPU load on the dashboard:** The GPU row now shows a load percentage beside temperature and watts, with a **Show GPU load** switch under **Settings > GPU > Dashboard readouts**. The reading follows the busiest GPU engine, so it agrees with Task Manager instead of the driver's separate utilization figure. No extra sensor poll was added.
- **Clearer value tooltips:** CPU clock, load, and package power, plus GPU temperature, power, load, and fan speed, now have localized tooltips. The GPU fan tooltip explains that 0 RPM is normal while the card is cool.
- **`GHz` label:** The CPU speed badge now uses the standard `GHz` capitalization.
- **CPU load and chart context:** CPU load appears beside the speed, charts show their minimum and maximum scale values, and the active power profile shows how long it has been running.
- **Limit Watch (opt-in):** A record-only watch reports when the measured CPU clock stays below nominal while the processor is busy. Results appear in the session report and as chart markers.
- **Sensor dropout log:** Logs CPU-only and total sensor loss after a sustained gap, without showing stale readings as current.
- **Power-plan drift notice:** Records when another program changes the active CryoTray plan and shows a tray notice, without switching the plan back.

Both the sensor dropout log and power-plan drift notice have switches under **Settings > General**. Limit Watch remains opt-in under **Settings > CPU**.

## Download

- **Installer (Recommended):** Download `CryoTray-Setup-0.0.106.exe` (includes the bundled PawnIO driver setup) and verify it against `CryoTray-Setup-0.0.106.exe.sha256`.
- **Portable Zip:** Download `CryoTray-0.0.106-win-x64.zip`, verify it against `CryoTray-0.0.106-win-x64.zip.sha256`, extract, run `PawnIO_setup.exe` if the driver is missing, then run `CryoTray.exe`.
- **In-app update:** Later versions arrive through **Settings > About** or the dashboard update banner.
