# CryoTray v0.0.108

## New

- **Per-mode sleep & display timeout overrides:** Configure persistent AC and DC **Turn off display** and **Put computer to sleep** timers separately for **Cooling On** (`Cooling`, `Legacy`, `Eco`) and **Cooling Off** (`Work`, `Gaming`) under **Settings > CPU > Sleep & display timeouts**, with a contextual **Reset** back to `Follow Windows` and automatic battery-column hiding on desktops.
- **Dashboard polish & snapshot copy:** Added a subtle fade behind hero temperature digits for higher contrast across all profile gradients, balanced the `22 px` telemetry gutter for extra pill breathing room, added a hover tooltip on the **GPU** header showing full card model, VRAM use, clocks, and throttle reason even with details hidden, added a collapsed-by-default active timer strip (`Keep Awake`, `Smart Download Timer`, and `Pause Cooling`) with a primary-timer **Stop** action, added **Tools > Copy snapshot** (`Ctrl+C`) respecting hidden drives, and preserved active profile uptime across close-to-tray.
- **Safer & richer Storage & Cache Cleanup:** Added a default-on **Skip temp files newer than 24 hours** guard, added an opt-in **Crash Dumps & Error Reports** category (`%LocalAppData%\CrashDumps`, `Minidump`, `WER`), added expandable **Locations** folder breakdowns with shortened path tokens, replaced the light scrollbar with a slim dark scrollbar, aligned card indicators, and color-matched rows to the distribution bar.
- **CPU Temperature Test upgrades:** Added **Auto A/B (60s)** mode (30s Cooling OFF followed by 30s Cooling ON with automatic plan restore), selectable load presets (`All Cores`, `Gaming 50%`, `1-Core Boost`), live package power and peak temperature cards, active plan display alongside `Cooling Mode`, a **Copy** summary button (`Ctrl+C`), chart scale labels with an empty-state prompt, high-contrast Start/Stop styling, and an automatic `95 °C` (`203 °F`) thermal safety cutoff.

## Fixes

- Reapplying **Settings > Reset** or **Import** now immediately syncs the active Windows power plan and timeout overrides.
- Editing unrelated Settings controls now preserves a Tray-selected or Game Mode active profile instead of overwriting it.
- Improved Settings Search (`Ctrl+F`) to skip hidden rows/collapsed disclosure bodies and navigate accurately onto collapsible toggle headers.
- Clearing or resetting the remembered CPU boost peak updates the live telemetry snapshot immediately across all GPU configurations.
- Expanded **Save support bundle...** settings diagnostics with preferred profile keys, tray badge color sync, and display/sleep timeout overrides.

## Download

- **Installer (Recommended):** Download `CryoTray-Setup-0.0.108.exe` (includes the bundled PawnIO driver setup) and verify it against `CryoTray-Setup-0.0.108.exe.sha256`.
- **Portable Zip:** Download `CryoTray-0.0.108-win-x64.zip`, verify it against `CryoTray-0.0.108-win-x64.zip.sha256`, extract, run `PawnIO_setup.exe` if the driver is missing, then run `CryoTray.exe`.
- **In-app update:** Later versions arrive through **Settings > About** or the dashboard update banner.
