# CryoTray v0.0.110

This release introduces the compact **CryoTray Lite** installer variant, removes the remaining Windows Forms dependency in favor of native WPF and Win32 tray rendering, cuts background CPU/page-fault overhead and package footprint, and improves interaction responsiveness.

## New: CryoTray Lite & Smaller Package Footprint

- **CryoTray Lite installer (`CryoTray-Lite-Setup-0.0.110.exe`):** A ~7.5 MB framework-dependent installer that bundles `LibreHardwareMonitorLib` and `PawnIO_setup.exe` offline while automatically installing the Microsoft .NET 10 Desktop Runtime only if missing.
- **Edition-aware auto-updater:** `UpdateService` automatically preserves your installed edition across updates (`Full` offline installs update via `CryoTray-Setup-*.exe`; `Lite` installs update via `CryoTray-Lite-Setup-*.exe`).
- **Smaller installers & disk footprint:** Excluded Linux/Unix `MonoPosix` native libraries (`libMonoPosixHelper.dll`, `MonoPosixHelper.dll`) from Windows builds, shrank embedded icon/logo assets cleanly while removing unused image candidates, and added silent post-install NTFS compression (`compact.exe`) in `CryoTray.iss` (~30–40% smaller installed folder on disk).

## Zero-WinForms Tray, Rendering & Memory Efficiency

- **Pure WPF & Win32 tray shell:** Removed the `System.Windows.Forms` (`UseWindowsForms`) dependency completely. Replaced the tray menu and color picker with a theme-cached WPF `ContextMenu` (`TrayIconManager`), native Win32 color dialog (`ColorDialogHelper`), and a reused Win32 GDI DIB `BadgeSurface` that updates live temperature badges with zero GDI handle leaks.
- **Responsive click & tab-switch protection:** Added `PauseForInteraction()` (`1200 ms`) across UI clicks, tray opens, and window activation plus a `5 s` anti-bounce cooldown (`MinDeactivatedInterval`) in `MemoryTrimService` so event-driven memory trimming stays around ~10 MB in tray idle without pausing active navigation.
- **Lower dashboard CPU & paint cost:** Decoupled the fan rotor from its drop-shadow glow tile (`FanGlowEffect`) to eliminate per-frame shader re-rasterization, reduced fan rotation to `15 fps`, added a 2-layer `ChartVisualHost` (`_gridVisual` + `_dataVisual`) with frozen brush/pen caches, and slowed chart redraws to `3 s` when unfocused.

## Download

- **Installer — Full Offline (Recommended):** Download `CryoTray-Setup-0.0.110.exe` (self-contained .NET 10 + bundled PawnIO driver setup; no runtime download required) and verify it against `CryoTray-Setup-0.0.110.exe.sha256`.
- **Installer — Lite (.NET 10 on demand):** Download `CryoTray-Lite-Setup-0.0.110.exe` (~7.5 MB; installs .NET 10 Desktop Runtime automatically if missing) and verify it against `CryoTray-Lite-Setup-0.0.110.exe.sha256`.
- **Portable Zip:** Download `CryoTray-0.0.110-win-x64.zip` (or `CryoTray-Lite-0.0.110-win-x64.zip`), verify its matching `.sha256` file, extract, run `PawnIO_setup.exe` if the driver is missing, then run `CryoTray.exe`.
- **In-app update:** Existing installs update cleanly through **Settings > About** or the dashboard update banner while matching your Full or Lite edition.
