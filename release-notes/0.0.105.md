# CryoTray v0.0.105

## Changes

- Migrated CryoTray to .NET 10 LTS (`net10.0-windows`) for better stability and a supported runtime.

## Download

- **Installer (Recommended):** Download `CryoTray-Setup-0.0.105.exe` (includes the bundled PawnIO driver setup) and verify it against `CryoTray-Setup-0.0.105.exe.sha256`.
- **Portable Zip:** Download `CryoTray-0.0.105-win-x64.zip`, verify it against `CryoTray-0.0.105-win-x64.zip.sha256`, extract, run `PawnIO_setup.exe` if the driver is missing, then run `CryoTray.exe`.
- **In-app update:** Later versions arrive through **Settings > About** or the dashboard update banner.
